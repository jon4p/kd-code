# Обновления KD Code

Подробности и актуальная загрузка: [keydealer.ru/kd-code](https://keydealer.ru/kd-code).

## 0.3.33 beta · KD Code Remote

- Удалённый запуск разрешённой локальной задачи через Telegram.
- Выбор проекта и отдельные команды для запуска, ответа и отмены.
- Новая Remote-задача начинается в режиме Plan; Build разрешается локально для конкретной папки.
- Фактическое списание приходит вместе с результатом.
- Версия KD Engine: 0.9.15.

KD Code должен быть открыт и находиться на связи. Telegram не использует end-to-end шифрование, поэтому через него нельзя отправлять секреты.
