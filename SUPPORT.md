# Поддержка KD Code

Для вопросов по установке, подключению ключа, моделям, списаниям и работе приложения используйте официальный канал поддержки:

**[Открыть поддержку KeyDealer →](https://keydealer.ru/app/support)**

Перед обращением укажите:

- операционную систему и её версию;
- версию KD Code;
- выбранную модель;
- текст сообщения об ошибке;
- приблизительное время проблемы по Москве.

Не публикуйте в GitHub Issues API-ключи, пароли, содержимое `.env`, приватный код, персональные данные и закрытые журналы. Секреты нельзя присылать и в поддержку; при необходимости сотрудник попросит безопасные диагностические сведения.

Публичные предложения по продукту и воспроизводимые ошибки без чувствительных данных можно оформить через GitHub Issues.
