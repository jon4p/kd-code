# Обратная связь по KD Code

Этот репозиторий служит официальной публичной витриной KD Code. Исходный код продукта здесь не размещён, поэтому pull request с реализацией функций не принимаются.

Вы можете:

- сообщить о воспроизводимой ошибке без чувствительных данных;
- предложить пользовательскую функцию;
- указать на неточность в публичном описании;
- предложить улучшение документации.

Перед публикацией проверьте, что сообщение не содержит ключей, секретов, приватного кода или персональных данных. Вопросы об аккаунте и списаниях направляйте в **[поддержку KeyDealer](https://keydealer.ru/app/support)**. Уязвимости сообщайте по инструкции из [SECURITY.md](SECURITY.md).
