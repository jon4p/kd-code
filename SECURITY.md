# Безопасность

Уязвимости KD Code, KeyDealer API и связанных сервисов нельзя раскрывать в публичном GitHub Issue.

Сообщите о проблеме через **[приватный диалог поддержки KeyDealer](https://keydealer.ru/app/support)** и добавьте пометку «Безопасность» в начале сообщения. Опишите затронутую версию, ожидаемое и фактическое поведение, а также безопасные шаги воспроизведения.

Не присылайте действующие API-ключи, пароли, приватные ключи, персональные данные или исходники закрытых проектов.

Этот репозиторий содержит публичные материалы о продукте. Исходный код KD Code и KD Engine здесь не опубликован.
